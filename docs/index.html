Как это работает

Задача GitHub Actions готовит новые карточки по статьям Wiktionary. Модель адаптирует английские определения. Примеры, русские переводы и транскрипции UK/US берутся из словарной статьи; при отсутствии полного примера слово пропускается. Уровни CEFR ориентировочные. Нужна дополнительная редакторская проверка сложных и спорных значений.

В карточках сохранены ссылки на источники, даты и лицензия CC BY-SA 4.0. Карточки прежнего каталога сохранены без изменения.

Телефон сохраняет загруженные слова для работы офлайн. Личный прогресс и свои слова не передаются в каталог. Если обновление задержалось или не прошло проверки, предыдущий выпуск остаётся доступен.
